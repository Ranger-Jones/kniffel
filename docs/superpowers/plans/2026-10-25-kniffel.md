# Kniffel Online Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein Online-Kniffel für Freunde mit Accounts, Echtzeit-Räumen (1–6 Spieler), Statistiken, Verlauf, Bestenliste, Freundesliste und Avatar-Upload – bunt & verspielt, gehostet auf Vercel + Supabase.

**Architecture:** Next.js (App Router) rendert alle Seiten und führt jede Spielaktion als Server Action aus. Eine reine TypeScript-Engine (`src/lib/kniffel`) entscheidet über Regeln und Zustand; dünne Service-Funktionen (`src/server/*-service.ts`) laden den Zustand mit dem Service-Role-Client, wenden die Engine an und speichern atomar über die Postgres-Funktion `commit_game` (optimistische Version). Clients lesen nur (RLS) und erhalten Änderungen über Supabase Realtime (`postgres_changes` auf `games`, Broadcast für Emojis, Presence für Online-Status).

**Tech Stack:** Next.js 16, React 19, TypeScript, Tailwind CSS 4, `@supabase/supabase-js` 2 + `@supabase/ssr`, Supabase CLI (lokal via Docker), zod 4, motion, canvas-confetti, sonner, Vitest 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-25-kniffel-design.md`

## Global Constraints

- Paketmanager: pnpm. Node 24.
- UI-Sprache Deutsch; alle Fehlermeldungen an Nutzer auf Deutsch.
- Klassische Regeln: Bonus 35 ab 63 oben; Full House 25 (genau 3+2, fünf gleiche zählen nicht); kleine Straße 30; große Straße 40; Kniffel 50; kein Extra-Kniffel-Bonus, keine Joker-Regel.
- 1–6 Spieler (`MAX_PLAYERS = 6`), 3 Würfe pro Zug, 13 Felder.
- Raum-Code: 6 Zeichen aus `ABCDEFGHJKLMNPQRSTUVWXYZ23456789`.
- Benutzername: 3–20 Zeichen `[A-Za-z0-9_]`, eindeutig ohne Groß/Klein-Unterschied.
- Passwort ≥ 8 Zeichen. Keine E-Mail-Bestätigung.
- Avatar: JPG/PNG/WebP, ≤ 2 MB, Ordner `avatars/<user_id>/`.
- Der Secret/Service-Role-Key wird nur serverseitig gelesen (`SUPABASE_SECRET_KEY`, nie `NEXT_PUBLIC_`).
- Clients schreiben nie direkt in `games`, `game_players`, `friendships`, `game_invites`, `profiles` – nur über Server Actions. Einzige direkte Client-Schreibaktion: Upload in Storage `avatars/<eigene id>/`.
- Würfeln nur serverseitig mit `crypto.randomInt(1, 7)`.
- Offline-Schwelle für „Zug überspringen“: 30 s. Überspringen trägt 0 im ersten freien Feld der Reihenfolge Einser → Chance ein.
- Emojis: 🎉 😂 😱 🔥 👏 😭, max. 1 pro Sekunde pro Client.
- `prefers-reduced-motion` wird respektiert.

## Review Focus

1. **Doppelklick auf „Würfeln“ / „Überspringen“** – darf nur einmal wirken. → Test in Task 5 (zwei parallele `roll`-Aufrufe mit gleicher `expectedVersion`: genau einer gewinnt).
2. **Benutzername in anderer Groß-/Kleinschreibung** („Max“ vs. „max“) – muss als vergeben gelten. → Test in Task 4.
3. **Beitritt in vollen / laufenden Raum oder mit kleingeschriebenem Code** – klare Meldung bzw. Code wird normalisiert. → Tests in Task 5.
4. **Host verlässt Lobby / letzter Spieler geht / Host wird mitten im Spiel entfernt** – Host wandert weiter, leeres Spiel wird gelöscht. → Tests in Task 3 und Task 5.
5. **Neu laden mitten im Zug** – Würfel, gehaltene Würfel, Punkte bleiben erhalten. → E2E in Task 13.

- [ ] **Step 4: `scoring.ts`**

```ts
import {
  CATEGORIES, LOWER_CATEGORIES, UPPER_BONUS, UPPER_BONUS_THRESHOLD, UPPER_CATEGORIES,
  type Category, type ScoreSheet,
} from './types';

function assertDice(dice: readonly number[]): void {
  if (dice.length !== 5 || dice.some((d) => !Number.isInteger(d) || d < 1 || d > 6)) {
    throw new Error(`Ungültige Würfel: ${JSON.stringify(dice)}`);
  }
}

function faceCounts(dice: readonly number[]): number[] {
  const counts = [0, 0, 0, 0, 0, 0, 0];
  for (const d of dice) counts[d]++;
  return counts;
}

function hasRun(counts: number[], length: number): boolean {
  let run = 0;
  for (let face = 1; face <= 6; face++) {
    run = counts[face] > 0 ? run + 1 : 0;
    if (run >= length) return true;
  }
  return false;
}

const sum = (dice: readonly number[]) => dice.reduce((a, b) => a + b, 0);

export function scoreCategory(category: Category, dice: readonly number[]): number {
  assertDice(dice);
  const counts = faceCounts(dice);
  const maxSame = Math.max(...counts);
  const upperIndex = (UPPER_CATEGORIES as readonly Category[]).indexOf(category);
  if (upperIndex >= 0) return counts[upperIndex + 1] * (upperIndex + 1);

  switch (category) {
    case 'threeKind': return maxSame >= 3 ? sum(dice) : 0;
    case 'fourKind': return maxSame >= 4 ? sum(dice) : 0;
    case 'fullHouse': return counts.includes(3) && counts.includes(2) ? 25 : 0;
    case 'smallStraight': return hasRun(counts, 4) ? 30 : 0;
    case 'largeStraight': return hasRun(counts, 5) ? 40 : 0;
    case 'kniffel': return maxSame === 5 ? 50 : 0;
    case 'chance': return sum(dice);
    default: throw new Error(`Unbekanntes Feld: ${category}`);
  }
}

export function emptySheet(): ScoreSheet {
  return Object.fromEntries(CATEGORIES.map((c) => [c, null])) as ScoreSheet;
}

const sumOf = (sheet: ScoreSheet, cats: readonly Category[]) =>
  cats.reduce((total, c) => total + (sheet[c] ?? 0), 0);

export const upperSum = (sheet: ScoreSheet) => sumOf(sheet, UPPER_CATEGORIES);
export const lowerSum = (sheet: ScoreSheet) => sumOf(sheet, LOWER_CATEGORIES);
export const upperBonus = (sheet: ScoreSheet) => (upperSum(sheet) >= UPPER_BONUS_THRESHOLD ? UPPER_BONUS : 0);
export const totalScore = (sheet: ScoreSheet) => upperSum(sheet) + upperBonus(sheet) + lowerSum(sheet);
export const filledCount = (sheet: ScoreSheet) => CATEGORIES.filter((c) => sheet[c] !== null).length;
export const isComplete = (sheet: ScoreSheet) => filledCount(sheet) === CATEGORIES.length;
```

```ts
import { emptySheet, filledCount, isComplete, scoreCategory, totalScore } from './scoring';
import { CATEGORIES, isCategory, type Category, type ScoreSheet } from './types';

export const MAX_PLAYERS = 6;
export const ROLLS_PER_TURN = 3;

export type GameStatus = 'lobby' | 'playing' | 'finished';
export interface PlayerSlot { id: string; left: boolean }
export interface GameState {
  status: GameStatus;
  hostId: string;
  players: PlayerSlot[];
  currentSeat: number;
  dice: (number | null)[];
  held: boolean[];
  rollsLeft: number;
  scores: Record<string, ScoreSheet>;
}
export type GameAction =
  | { type: 'join' }
  | { type: 'leave' }
  | { type: 'start' }
  | { type: 'roll' }
  | { type: 'setHold'; index: number; held: boolean }
  | { type: 'score'; category: Category }
  | { type: 'skipTurn' }
  | { type: 'removePlayer'; playerId: string };
export type RollDie = () => number;
export type EngineResult = { ok: true; state: GameState } | { ok: false; error: string };

const ok = (state: GameState): EngineResult => ({ ok: true, state });
const fail = (error: string): EngineResult => ({ ok: false, error });

function freshTurn() {
  return { dice: [null, null, null, null, null], held: [false, false, false, false, false], rollsLeft: ROLLS_PER_TURN };
}

export function createGameState(hostId: string): GameState {
  return createRematchState(hostId, [hostId]);
}

export function createRematchState(hostId: string, playerIds: string[]): GameState {
  return {
    status: 'lobby',
    hostId,
    players: playerIds.map((id) => ({ id, left: false })),
    currentSeat: 0,
    ...freshTurn(),
    scores: Object.fromEntries(playerIds.map((id) => [id, emptySheet()])),
  };
}

export const activePlayers = (state: GameState) => state.players.filter((p) => !p.left);

export function currentPlayerId(state: GameState): string | null {
  return state.status === 'playing' ? (state.players[state.currentSeat]?.id ?? null) : null;
}

export function currentRound(state: GameState): number {
  const active = activePlayers(state);
  if (active.length === 0) return 1;
  return Math.min(13, 1 + Math.min(...active.map((p) => filledCount(state.scores[p.id]))));
}

export function placements(state: GameState): Record<string, number> {
  const totals = activePlayers(state).map((p) => ({ id: p.id, total: totalScore(state.scores[p.id]) }));
  return Object.fromEntries(totals.map((p) => [p.id, 1 + totals.filter((o) => o.total > p.total).length]));
}

/** Nächster aktiver Spieler mit offenem Zettel nach currentSeat; sonst Spielende. */
function advanceTurn(state: GameState): GameState {
  const n = state.players.length;
  for (let step = 1; step <= n; step++) {
    const seat = (state.currentSeat + step) % n;
    const p = state.players[seat];
    if (!p.left && !isComplete(state.scores[p.id])) return { ...state, ...freshTurn(), currentSeat: seat };
  }
  return { ...state, ...freshTurn(), status: 'finished' };
}

function nextActiveAfter(players: PlayerSlot[], seat: number): PlayerSlot | undefined {
  for (let step = 1; step <= players.length; step++) {
    const p = players[(seat + step) % players.length];
    if (!p.left) return p;
  }
  return undefined;
}

function withoutPlayer(state: GameState, playerId: string): GameState {
  if (state.status === 'lobby') {
    const players = state.players.filter((p) => p.id !== playerId);
    const { [playerId]: _removed, ...scores } = state.scores;
    const hostId = state.hostId === playerId ? (players[0]?.id ?? state.hostId) : state.hostId;
    return { ...state, players, scores, hostId, currentSeat: 0 };
  }
  const seat = state.players.findIndex((p) => p.id === playerId);
  const players = state.players.map((p) => (p.id === playerId ? { ...p, left: true } : p));
  let next: GameState = { ...state, players };
  if (players.every((p) => p.left)) return { ...next, ...freshTurn(), status: 'finished' };
  if (state.hostId === playerId) next.hostId = nextActiveAfter(players, seat)!.id;
  if (state.currentSeat === seat) next = advanceTurn(next);
  return next;
}

function requireTurn(state: GameState, actorId: string): string | null {
  if (state.status === 'lobby') return 'Das Spiel hat noch nicht begonnen.';
  if (currentPlayerId(state) !== actorId) return 'Du bist nicht am Zug.';
  return null;
}

export function applyAction(state: GameState, actorId: string, action: GameAction, rollDie: RollDie): EngineResult {
  if (state.status === 'finished') return fail('Das Spiel ist bereits beendet.');
  const isActiveMember = state.players.some((p) => p.id === actorId && !p.left);
  const isHost = state.hostId === actorId;

  switch (action.type) {
    case 'join': {
      if (state.status !== 'lobby') return fail('Das Spiel läuft bereits.');
      if (state.players.some((p) => p.id === actorId)) return ok(state);
      if (state.players.length >= MAX_PLAYERS) return fail('Der Raum ist voll.');
      return ok({
        ...state,
        players: [...state.players, { id: actorId, left: false }],
        scores: { ...state.scores, [actorId]: emptySheet() },
      });
    }
    case 'leave':
      if (!isActiveMember) return fail('Du bist nicht in diesem Spiel.');
      return ok(withoutPlayer(state, actorId));
    case 'removePlayer': {
      if (!isHost) return fail('Nur der Host kann Spieler entfernen.');
      if (action.playerId === actorId) return fail('Du kannst dich nicht selbst entfernen.');
      if (!state.players.some((p) => p.id === action.playerId && !p.left)) return fail('Spieler nicht gefunden.');
      return ok(withoutPlayer(state, action.playerId));
    }
    case 'start':
      if (state.status !== 'lobby') return fail('Das Spiel läuft bereits.');
      if (!isHost) return fail('Nur der Host kann das Spiel starten.');
      return ok({ ...state, status: 'playing', currentSeat: 0, ...freshTurn() });
    case 'roll': {
      const err = requireTurn(state, actorId);
      if (err) return fail(err);
      if (state.rollsLeft <= 0) return fail('Keine Würfe mehr übrig.');
      const dice = state.dice.map((d, i) => (state.held[i] && d !== null ? d : rollDie()));
      return ok({ ...state, dice, rollsLeft: state.rollsLeft - 1 });
    }
    case 'setHold': {
      const err = requireTurn(state, actorId);
      if (err) return fail(err);
      if (state.rollsLeft === ROLLS_PER_TURN) return fail('Erst würfeln.');
      if (!Number.isInteger(action.index) || action.index < 0 || action.index > 4) return fail('Ungültiger Würfel.');
      if (state.rollsLeft === 0) return fail('Keine Würfe mehr übrig.');
      const held = state.held.map((h, i) => (i === action.index ? action.held : h));
      return ok({ ...state, held });
    }
    case 'score': {
      const err = requireTurn(state, actorId);
      if (err) return fail(err);
      if (state.rollsLeft === ROLLS_PER_TURN) return fail('Erst würfeln.');
      if (!isCategory(action.category)) return fail('Unbekanntes Feld.');
      const sheet = state.scores[actorId];
      if (sheet[action.category] !== null) return fail('Dieses Feld ist schon belegt.');
      const value = scoreCategory(action.category, state.dice as number[]);
      const scores = { ...state.scores, [actorId]: { ...sheet, [action.category]: value } };
      return ok(advanceTurn({ ...state, scores }));
    }
    case 'skipTurn': {
      if (state.status !== 'playing') return fail('Das Spiel hat noch nicht begonnen.');
      if (!isHost) return fail('Nur der Host kann Züge überspringen.');
      const targetId = currentPlayerId(state)!;
      if (targetId === actorId) return fail('Du kannst deinen eigenen Zug nicht überspringen.');
      const sheet = state.scores[targetId];
      const free = CATEGORIES.find((c) => sheet[c] === null)!;
      const scores = { ...state.scores, [targetId]: { ...sheet, [free]: 0 } };
      return ok(advanceTurn({ ...state, scores }));
    }
  }
}
```

```ts
import { randomInt } from 'node:crypto';
import {
  applyAction, createGameState, createRematchState, placements,
  type GameAction, type GameState,
} from '@/lib/kniffel/engine';
import { totalScore } from '@/lib/kniffel/scoring';
import type { AdminClient } from '@/lib/supabase/admin';
import { fail, ok, STALE, type ServiceResult } from './result';

export const CODE_ALPHABET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789';
const rollDie = () => randomInt(1, 7);

export interface GameRow { id: string; code: string; version: number; state: GameState; rematchGameId: string | null }

export function normalizeCode(input: string): string {
  return input.trim().toUpperCase().replace(/[^A-Z0-9]/g, '');
}

function generateCode(): string {
  return Array.from({ length: 6 }, () => CODE_ALPHABET[randomInt(CODE_ALPHABET.length)]).join('');
}

type Row = { id: string; code: string; version: number; state: unknown; rematch_game_id: string | null };
const toGame = (r: Row): GameRow => ({
  id: r.id, code: r.code, version: r.version, state: r.state as GameState, rematchGameId: r.rematch_game_id,
});
const COLUMNS = 'id, code, version, state, rematch_game_id';

export async function loadGame(admin: AdminClient, id: string): Promise<GameRow | null> {
  const { data, error } = await admin.from('games').select(COLUMNS).eq('id', id).maybeSingle();
  if (error) throw error;
  return data ? toGame(data) : null;
}

export async function loadGameByCode(admin: AdminClient, code: string): Promise<GameRow | null> {
  const { data, error } = await admin.from('games').select(COLUMNS).eq('code', normalizeCode(code)).maybeSingle();
  if (error) throw error;
  return data ? toGame(data) : null;
}

function playersPayload(state: GameState) {
  const places = state.status === 'finished' ? placements(state) : {};
  return state.players.map((p, seat) => ({
    userId: p.id, seat, left: p.left, scores: state.scores[p.id],
    total: totalScore(state.scores[p.id]), place: places[p.id] ?? null,
  }));
}

async function commit(admin: AdminClient, gameId: string, expectedVersion: number, state: GameState): Promise<number | 'conflict'> {
  const { data, error } = await admin.rpc('commit_game', {
    p_game_id: gameId, p_expected_version: expectedVersion,
    p_state: state as never, p_players: playersPayload(state) as never,
  });
  if (error) {
    if (error.message.includes('version_conflict')) return 'conflict';
    throw error;
  }
  return data;
}

async function insertGame(admin: AdminClient, state: GameState): Promise<ServiceResult<{ id: string; code: string }>> {
  for (let attempt = 0; attempt < 5; attempt++) {
    const code = generateCode();
    const { data, error } = await admin.from('games')
      .insert({ code, host_id: state.hostId, status: 'lobby', state: state as never })
      .select('id').single();
    if (error) {
      if (error.code === '23505') continue;
      throw error;
    }
    await commit(admin, data.id, 0, state);
    return ok({ id: data.id, code });
  }
  return fail('Konnte keinen Raum-Code erzeugen. Bitte nochmal versuchen.');
}

export function createGame(admin: AdminClient, userId: string) {
  return insertGame(admin, createGameState(userId));
}

export async function performAction(
  admin: AdminClient, userId: string, gameId: string, action: GameAction, expectedVersion?: number,
): Promise<ServiceResult<{ version: number; state: GameState }>> {
  for (let attempt = 0; attempt < 2; attempt++) {
    const game = await loadGame(admin, gameId);
    if (!game) return fail('Spiel nicht gefunden.');
    if (expectedVersion !== undefined && game.version !== expectedVersion) return fail(STALE);

    const res = applyAction(game.state, userId, action, rollDie);
    if (!res.ok) return fail(res.error);
    if (res.state === game.state) return ok({ version: game.version, state: game.state });

    if (res.state.players.length === 0) {
      await admin.from('games').delete().eq('id', gameId).eq('version', game.version);
      return ok({ version: game.version + 1, state: res.state });
    }
    const version = await commit(admin, gameId, game.version, res.state);
    if (version !== 'conflict') return ok({ version, state: res.state });
    if (expectedVersion !== undefined) return fail(STALE);
  }
  return fail('Gleichzeitige Aktion – bitte nochmal versuchen.');
}

export async function joinGame(admin: AdminClient, userId: string, code: string): Promise<ServiceResult<{ code: string }>> {
  const game = await loadGameByCode(admin, code);
  if (!game) return fail('Kein Spiel mit diesem Code gefunden.');
  const res = await performAction(admin, userId, game.id, { type: 'join' });
  return res.ok ? ok({ code: game.code }) : res;
}

export async function requestRematch(admin: AdminClient, userId: string, gameId: string): Promise<ServiceResult<{ code: string }>> {
  const game = await loadGame(admin, gameId);
  if (!game) return fail('Spiel nicht gefunden.');
  if (game.state.status !== 'finished') return fail('Das Spiel ist noch nicht beendet.');
  if (!game.state.players.some((p) => p.id === userId && !p.left)) return fail('Du warst nicht in diesem Spiel.');

  const existing = async (id: string | null) => (id ? loadGame(admin, id) : null);
  const already = await existing(game.rematchGameId);
  if (already) return ok({ code: already.code });

  const playerIds = game.state.players.filter((p) => !p.left).map((p) => p.id);
  const created = await insertGame(admin, createRematchState(userId, playerIds));
  if (!created.ok) return created;

  const { data } = await admin.from('games')
    .update({ rematch_game_id: created.data.id })
    .eq('id', gameId).is('rematch_game_id', null).select('id');
  if (data && data.length > 0) return ok({ code: created.data.code });

  // Jemand anderes war schneller: eigenes Spiel verwerfen, das andere nehmen.
  await admin.from('games').delete().eq('id', created.data.id);
  const winner = await existing((await loadGame(admin, gameId))?.rematchGameId ?? null);
  return winner ? ok({ code: winner.code }) : fail('Revanche konnte nicht erstellt werden.');
}
```

```ts
import type { AdminClient } from '@/lib/supabase/admin';
import { joinGame, loadGame } from './game-service';
import { fail, ok, type ServiceResult } from './result';
import { MAX_PLAYERS } from '@/lib/kniffel/engine';

export interface ProfileLite { id: string; username: string; avatar_url: string | null }
export interface FriendEntry { friendshipId: string; profile: ProfileLite }
export interface FriendLists { friends: FriendEntry[]; incoming: FriendEntry[]; outgoing: FriendEntry[] }
export interface PendingInvite { id: string; gameCode: string; from: ProfileLite; createdAt: string }

const PROFILE_COLS = 'id, username, avatar_url';

export async function searchProfiles(admin: AdminClient, userId: string, query: string): Promise<ProfileLite[]> {
  const q = query.trim().replace(/[^A-Za-z0-9_]/g, '');
  if (q.length < 2) return [];
  const { data, error } = await admin.from('profiles').select(PROFILE_COLS)
    .ilike('username', `${q}%`).neq('id', userId).order('username').limit(10);
  if (error) throw error;
  return data;
}

async function findFriendship(admin: AdminClient, x: string, y: string) {
  const { data, error } = await admin.from('friendships').select('*')
    .or(`and(requester_id.eq.${x},addressee_id.eq.${y}),and(requester_id.eq.${y},addressee_id.eq.${x})`)
    .maybeSingle();
  if (error) throw error;
  return data;
}

export async function sendFriendRequest(admin: AdminClient, userId: string, username: string): Promise<ServiceResult<{ status: 'pending' | 'accepted' }>> {
  const { data: target } = await admin.from('profiles').select('id').eq('username', username.trim()).maybeSingle();
  if (!target) return fail('Benutzer nicht gefunden.');
  if (target.id === userId) return fail('Das bist du selbst.');
  const existing = await findFriendship(admin, userId, target.id);
  if (existing?.status === 'accepted') return fail('Ihr seid schon befreundet.');
  if (existing?.requester_id === userId) return fail('Anfrage bereits gesendet.');
  if (existing) {
    await admin.from('friendships').update({ status: 'accepted' }).eq('id', existing.id);
    return ok({ status: 'accepted' as const });
  }
  const { error } = await admin.from('friendships').insert({ requester_id: userId, addressee_id: target.id });
  if (error) throw error;
  return ok({ status: 'pending' as const });
}

export async function respondFriendRequest(admin: AdminClient, userId: string, friendshipId: string, accept: boolean): Promise<ServiceResult> {
  const { data: f } = await admin.from('friendships').select('*').eq('id', friendshipId).maybeSingle();
  if (!f || f.addressee_id !== userId || f.status !== 'pending') return fail('Anfrage nicht gefunden.');
  const { error } = accept
    ? await admin.from('friendships').update({ status: 'accepted' }).eq('id', friendshipId)
    : await admin.from('friendships').delete().eq('id', friendshipId);
  if (error) throw error;
  return ok(undefined);
}

export async function removeFriend(admin: AdminClient, userId: string, friendshipId: string): Promise<ServiceResult> {
  const { data: f } = await admin.from('friendships').select('*').eq('id', friendshipId).maybeSingle();
  if (!f || (f.requester_id !== userId && f.addressee_id !== userId)) return fail('Freundschaft nicht gefunden.');
  await admin.from('friendships').delete().eq('id', friendshipId);
  return ok(undefined);
}

export async function listFriends(admin: AdminClient, userId: string): Promise<FriendLists> {
  const { data, error } = await admin.from('friendships')
    .select(`id, status, requester_id, addressee_id,
      requester:profiles!friendships_requester_id_fkey(${PROFILE_COLS}),
      addressee:profiles!friendships_addressee_id_fkey(${PROFILE_COLS})`)
    .or(`requester_id.eq.${userId},addressee_id.eq.${userId}`);
  if (error) throw error;
  const lists: FriendLists = { friends: [], incoming: [], outgoing: [] };
  for (const f of data) {
    const mine = f.requester_id === userId;
    const entry = { friendshipId: f.id, profile: (mine ? f.addressee : f.requester) as ProfileLite };
    if (f.status === 'accepted') lists.friends.push(entry);
    else (mine ? lists.outgoing : lists.incoming).push(entry);
  }
  const byName = (x: FriendEntry, y: FriendEntry) => x.profile.username.localeCompare(y.profile.username);
  lists.friends.sort(byName); lists.incoming.sort(byName); lists.outgoing.sort(byName);
  return lists;
}

export async function inviteToGame(admin: AdminClient, userId: string, gameId: string, friendId: string): Promise<ServiceResult> {
  const game = await loadGame(admin, gameId);
  if (!game) return fail('Spiel nicht gefunden.');
  if (game.state.status !== 'lobby') return fail('Das Spiel läuft bereits.');
  if (!game.state.players.some((p) => p.id === userId)) return fail('Du bist nicht in diesem Spiel.');
  if (game.state.players.some((p) => p.id === friendId)) return fail('Ist schon im Spiel.');
  if (game.state.players.length >= MAX_PLAYERS) return fail('Der Raum ist voll.');
  const f = await findFriendship(admin, userId, friendId);
  if (f?.status !== 'accepted') return fail('Ihr seid nicht befreundet.');
  const { error } = await admin.from('game_invites').upsert(
    { game_id: gameId, from_id: userId, to_id: friendId, status: 'pending', created_at: new Date().toISOString() },
    { onConflict: 'game_id,to_id' },
  );
  if (error) throw error;
  return ok(undefined);
}

export async function respondInvite(admin: AdminClient, userId: string, inviteId: string, accept: boolean): Promise<ServiceResult<{ code: string | null }>> {
  const { data: inv } = await admin.from('game_invites').select('id, to_id, status, games(code)').eq('id', inviteId).maybeSingle();
  if (!inv || inv.to_id !== userId || inv.status !== 'pending') return fail('Einladung nicht gefunden.');
  if (!accept) {
    await admin.from('game_invites').update({ status: 'declined' }).eq('id', inviteId);
    return ok({ code: null });
  }
  const code = (inv.games as { code: string } | null)?.code;
  if (!code) return fail('Das Spiel existiert nicht mehr.');
  const joined = await joinGame(admin, userId, code);
  if (!joined.ok) return joined;
  await admin.from('game_invites').update({ status: 'accepted' }).eq('id', inviteId);
  return ok({ code });
}

export async function listPendingInvites(admin: AdminClient, userId: string): Promise<PendingInvite[]> {
  const { data, error } = await admin.from('game_invites')
    .select(`id, created_at, games!inner(code, status), from:profiles!game_invites_from_id_fkey(${PROFILE_COLS})`)
    .eq('to_id', userId).eq('status', 'pending').eq('games.status', 'lobby')
    .order('created_at', { ascending: false });
  if (error) throw error;
  return data.map((i) => ({
    id: i.id, createdAt: i.created_at,
    gameCode: (i.games as { code: string }).code, from: i.from as ProfileLite,
  }));
}
```

```ts
'use server';
import { redirect } from 'next/navigation';
import { z } from 'zod';
import { createAdminClient } from '@/lib/supabase/admin';
import { createServerSupabase } from '@/lib/supabase/server';
import { isUsernameTaken, USERNAME_RE } from './profile-service';

export type AuthState = { error?: string };

const safeNext = (v: FormDataEntryValue | null) => {
  const s = typeof v === 'string' ? v : '';
  return s.startsWith('/') && !s.startsWith('//') ? s : '/';
};

const signUpSchema = z.object({
  email: z.email('Bitte eine gültige E-Mail eingeben.'),
  password: z.string().min(8, 'Passwort: mindestens 8 Zeichen.'),
  username: z.string().trim().regex(USERNAME_RE, 'Benutzername: 3–20 Zeichen, nur Buchstaben, Zahlen und _.'),
});

export async function signUp(_: AuthState, form: FormData): Promise<AuthState> {
  const parsed = signUpSchema.safeParse(Object.fromEntries(form));
  if (!parsed.success) return { error: parsed.error.issues[0].message };
  const { email, password, username } = parsed.data;
  if (await isUsernameTaken(createAdminClient(), username)) return { error: 'Benutzername ist schon vergeben.' };
  const supabase = await createServerSupabase();
  const { error } = await supabase.auth.signUp({ email, password, options: { data: { username } } });
  if (error) {
    if (/already registered/i.test(error.message)) return { error: 'Diese E-Mail ist schon registriert.' };
    return { error: 'Registrierung fehlgeschlagen. Bitte nochmal versuchen.' };
  }
  redirect(safeNext(form.get('next')));
}

export async function signIn(_: AuthState, form: FormData): Promise<AuthState> {
  const supabase = await createServerSupabase();
  const { error } = await supabase.auth.signInWithPassword({
    email: String(form.get('email') ?? ''), password: String(form.get('password') ?? ''),
  });
  if (error) return { error: 'E-Mail oder Passwort falsch.' };
  redirect(safeNext(form.get('next')));
}

export async function signOut() {
  const supabase = await createServerSupabase();
  await supabase.auth.signOut();
  redirect('/');
}
```

```ts
import { redirect } from 'next/navigation';
import { z } from 'zod';
import { CATEGORIES } from '@/lib/kniffel/types';
import type { GameAction } from '@/lib/kniffel/engine';
import { createAdminClient } from '@/lib/supabase/admin';
import { requireUser } from '@/lib/supabase/server';
import { createGame, joinGame, performAction, requestRematch } from './game-service';
import { fail } from './result';
import { inviteToGame } from './social-service';

const actionSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('leave') }),
  z.object({ type: z.literal('start') }),
  z.object({ type: z.literal('roll') }),
  z.object({ type: z.literal('setHold'), index: z.number().int().min(0).max(4), held: z.boolean() }),
  z.object({ type: z.literal('score'), category: z.enum(CATEGORIES) }),
  z.object({ type: z.literal('skipTurn') }),
  z.object({ type: z.literal('removePlayer'), playerId: z.uuid() }),
]);

export async function createGameAction() {
  const user = await requireUser();
  const res = await createGame(createAdminClient(), user.id);
  if (!res.ok) throw new Error(res.error);
  redirect(`/spiel/${res.data.code}`);
}

export async function joinGameAction(_: { error?: string }, form: FormData) {
  const user = await requireUser();
  const res = await joinGame(createAdminClient(), user.id, String(form.get('code') ?? ''));
  if (!res.ok) return { error: res.error };
  redirect(`/spiel/${res.data.code}`);
}

export async function gameAction(gameId: string, action: GameAction, expectedVersion?: number) {
  const user = await requireUser();
  const parsed = actionSchema.safeParse(action);
  if (!parsed.success || !z.uuid().safeParse(gameId).success) return fail('Ungültige Aktion.');
  return performAction(createAdminClient(), user.id, gameId, parsed.data, expectedVersion);
}

export async function rematchAction(gameId: string) {
  const user = await requireUser();
  return requestRematch(createAdminClient(), user.id, gameId);
}

export async function inviteAction(gameId: string, friendId: string) {
  const user = await requireUser();
  return inviteToGame(createAdminClient(), user.id, gameId, friendId);
}
```

```ts
'use client';
import { useCallback, useEffect, useRef, useState } from 'react';
import { toast } from 'sonner';
import type { GameAction, GameState } from '@/lib/kniffel/engine';
import { createBrowserSupabase } from '@/lib/supabase/browser';
import { gameAction } from '@/server/game-actions';
import { STALE } from '@/server/result';
import type { ProfileLite } from '@/server/social-service';

export interface GameSnapshot { id: string; code: string; version: number; state: GameState; rematchGameId: string | null }

type Row = { id: string; code: string; version: number; state: unknown; rematch_game_id: string | null };
const toSnapshot = (r: Row): GameSnapshot => ({ id: r.id, code: r.code, version: r.version, state: r.state as GameState, rematchGameId: r.rematch_game_id });

export function useGame(initial: GameSnapshot, initialProfiles: Record<string, ProfileLite>, me: string) {
  const supabase = createBrowserSupabase();
  const [game, setGame] = useState<GameSnapshot | null>(initial);
  const [profiles, setProfiles] = useState(initialProfiles);
  const [online, setOnline] = useState<Set<string>>(new Set([me]));
  const [offlineSince, setOfflineSince] = useState<Record<string, number>>({});
  const [connected, setConnected] = useState(true);
  const [emojis, setEmojis] = useState<{ id: string; emoji: string; from: string }[]>([]);
  const channelRef = useRef<ReturnType<typeof supabase.channel> | null>(null);
  const lastEmoji = useRef(0);

  const apply = useCallback((next: GameSnapshot) => {
    setGame((cur) => (!cur || next.version > cur.version || next.rematchGameId !== cur.rematchGameId ? next : cur));
  }, []);

  const refetch = useCallback(async () => {
    const { data } = await supabase.from('games').select('id, code, version, state, rematch_game_id').eq('id', initial.id).maybeSingle();
    if (data) apply(toSnapshot(data)); else setGame(null);
  }, [apply, initial.id, supabase]);

  // fehlende Profile nachladen, wenn neue Spieler beitreten
  useEffect(() => {
    const missing = game?.state.players.map((p) => p.id).filter((id) => !profiles[id]) ?? [];
    if (missing.length === 0) return;
    supabase.from('profiles').select('id, username, avatar_url').in('id', missing).then(({ data }) => {
      if (data) setProfiles((p) => ({ ...p, ...Object.fromEntries(data.map((x) => [x.id, x])) }));
    });
  }, [game?.state.players, profiles, supabase]);

  useEffect(() => {
    const channel = supabase.channel(`game:${initial.id}`, { config: { presence: { key: me } } });
    channelRef.current = channel;
    channel
      .on('postgres_changes', { event: 'UPDATE', schema: 'public', table: 'games', filter: `id=eq.${initial.id}` },
        (payload) => apply(toSnapshot(payload.new as Row)))
      .on('postgres_changes', { event: 'DELETE', schema: 'public', table: 'games', filter: `id=eq.${initial.id}` },
        () => setGame(null))
      .on('broadcast', { event: 'emoji' }, ({ payload }) => {
        setEmojis((e) => [...e.slice(-15), payload as { id: string; emoji: string; from: string }]);
      })
      .on('presence', { event: 'sync' }, () => {
        const ids = new Set(Object.keys(channel.presenceState()));
        setOnline(ids);
        setOfflineSince((prev) => {
          const next: Record<string, number> = {};
          for (const [id, t] of Object.entries(prev)) if (!ids.has(id)) next[id] = t;
          return next;
        });
      })
      .on('presence', { event: 'leave' }, ({ key }) => setOfflineSince((p) => ({ ...p, [key]: p[key] ?? Date.now() })))
      .subscribe(async (status) => {
        if (status === 'SUBSCRIBED') {
          setConnected(true);
          await channel.track({ at: Date.now() });
          await refetch();
        } else if (status === 'CHANNEL_ERROR' || status === 'TIMED_OUT' || status === 'CLOSED') {
          setConnected(false);
        }
      });
    return () => { supabase.removeChannel(channel); };
  }, [apply, initial.id, me, refetch, supabase]);

  const dispatch = useCallback(async (action: GameAction, opts: { versioned?: boolean } = {}) => {
    if (!game) return;
    const res = await gameAction(game.id, action, opts.versioned ? game.version : undefined);
    if (res.ok) apply({ ...game, version: res.data.version, state: res.data.state });
    else if (res.error !== STALE) toast.error(res.error);
  }, [apply, game]);

  const sendEmoji = useCallback((emoji: string) => {
    if (Date.now() - lastEmoji.current < 1000) return;
    lastEmoji.current = Date.now();
    const payload = { id: crypto.randomUUID(), emoji, from: me };
    setEmojis((e) => [...e.slice(-15), payload]);
    channelRef.current?.send({ type: 'broadcast', event: 'emoji', payload });
  }, [me]);

  return { game, profiles, online, offlineSince, connected, emojis, sendEmoji, dispatch };
}
```

```ts
import { expect, test, type Page } from '@playwright/test';

const run = Date.now().toString(36);

async function register(page: Page, name: string) {
  await page.goto('/registrieren');
  await page.getByLabel('Benutzername').fill(name);
  await page.getByLabel('E-Mail').fill(`${name}@test.local`);
  await page.getByLabel('Passwort').fill('passwort123');
  await page.getByRole('button', { name: 'Account erstellen' }).click();
  await expect(page.getByText(`Hey ${name}`)).toBeVisible();
}

async function playTurn(page: Page) {
  await page.getByTestId('roll-button').click();
  const option = page.getByTestId('score-option').first();
  await expect(option).toBeVisible();
  await option.click();
  const strike = page.getByRole('button', { name: 'Streichen' });
  if (await strike.isVisible().catch(() => false)) await strike.click();
}

test('zwei Freunde spielen ein komplettes Spiel', async ({ browser }) => {
  const a = await (await browser.newContext()).newPage();
  const b = await (await browser.newContext()).newPage();
  const nameA = `ali_${run}`, nameB = `bob_${run}`;
  await register(a, nameA);
  await register(b, nameB);

  // Freundschaft
  await a.goto('/freunde');
  await a.getByPlaceholder('Benutzername suchen').fill(nameB);
  await a.getByRole('button', { name: 'Anfrage senden' }).click();
  await b.goto('/freunde');
  await b.getByRole('button', { name: 'Annehmen' }).click();
  await expect(b.getByText(nameA)).toBeVisible();

  // Spiel + Einladung
  await a.goto('/');
  await a.getByRole('button', { name: 'Neues Spiel' }).click();
  await expect(a).toHaveURL(/\/spiel\/[A-Z0-9]{6}$/);
  await b.goto('/');
  await a.getByRole('button', { name: 'Einladen' }).click();
  await b.getByRole('button', { name: 'Beitreten' }).first().click();
  await expect(b).toHaveURL(a.url());
  await expect(a.getByText(nameB)).toBeVisible();

  await a.getByRole('button', { name: 'Spiel starten' }).click();

  for (let turn = 0; turn < 26; turn++) {
    const current = turn % 2 === 0 ? a : b;
    const other = turn % 2 === 0 ? b : a;
    await expect(current.getByTestId('turn-indicator')).toHaveText(/Du bist dran/);
    if (turn === 7) {
      // Reload mitten im Zug: Würfel bleiben erhalten
      await current.getByTestId('roll-button').click();
      const before = await current.getByTestId('die-0').getAttribute('data-value');
      await current.reload();
      await expect(current.getByTestId('die-0')).toHaveAttribute('data-value', before!);
      await current.getByTestId('score-option').first().click();
      const strike = current.getByRole('button', { name: 'Streichen' });
      if (await strike.isVisible().catch(() => false)) await strike.click();
    } else {
      await playTurn(current);
    }
    if (turn < 25) await expect(other.getByTestId('turn-indicator')).toHaveText(/Du bist dran/);
  }

  await expect(a.getByText('Spiel beendet!')).toBeVisible();
  await expect(b.getByText('Spiel beendet!')).toBeVisible();

  // Revanche
  const oldUrl = a.url();
  await a.getByRole('button', { name: 'Revanche' }).click();
  await expect(a).not.toHaveURL(oldUrl);
  await expect(b).toHaveURL(a.url());

  // Statistik
  await a.goto(`/profil/${nameA}`);
  await expect(a.getByTestId('stat-games')).toHaveText('1');
});
```
